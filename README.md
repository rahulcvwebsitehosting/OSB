# OSB Hot & Chat

Modern digital storefront and menu platform for West Mambalam’s premier pure-vegetarian street food destination.

## Description

OSB Hot & Chat is a comprehensive web application designed to bridge the gap between traditional street food services and modern digital convenience. Located in Ramakrishnapuram, West Mambalam, the physical establishment has been a local landmark since 2008. 

This platform provides a high-performance, mobile-optimized interface for customers to explore a diverse menu of over 100+ items, ranging from authentic North Indian chaats to South Indian tiffin. It solves the challenge of menu accessibility and provides transparency through detailed nutritional information, specifically catering to health-conscious diners and fitness enthusiasts in the local community.

## Features

*   Dynamic Digital Menu: Categorized browsing with real-time search and price filtering across 14 food categories.
*   Gym Bro’s Corner: A dedicated nutritional module providing estimated macronutrient data (protein, carbs, fats, calories) for high-protein vegetarian options.
*   Mobile-First Architecture: Native-like navigation bar and glassmorphism UI elements optimized for small-screen accessibility.
*   Direct Integration: Seamless transition to Swiggy for delivery and WhatsApp for direct customer inquiries.
*   Interactive Mapping: Integrated location services with live business hours tracking and popular times visualization.
*   SEO & Performance: Lightweight architecture built for fast loading on mobile networks with optimized asset delivery.

## Tech Stack

*   Frontend: React 19, TypeScript
*   Build Tooling: Vite
*   Styling: Tailwind CSS
*   Routing: React Router 6

## Installation & Setup

Follow these steps to set up the project locally for development:

1. Clone the repository:
   ```bash
   git clone https://github.com/rahulshyamcivil/osb-hot-chat.git
   ```

2. Navigate to the project directory:
   ```bash
   cd osb-hot-chat
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```

## Usage

The application is designed for intuitive navigation:
*   Navigate through the bottom sticky bar (Mobile) or top navigation links (Desktop).
*   Use the "Menu" page to filter items by category or price range.
*   Check the "About" page for detailed allergen information and protein-focused meal recommendations.
*   Use the "Map" or "Location" page to find directions via Google Maps API integration.
*   Click the "Order on Swiggy" button to be redirected to the official delivery storefront.
